# Bài tập thực hành Git và GitHub

## Mục tiêu
Thực hành tạo repository mới, khởi tạo Local Repository, kết nối với Remote Repository và đưa mã nguồn lên GitHub bằng các lệnh Git cơ bản.

## Các lệnh đã sử dụng
- `git init`: khởi tạo Git Repository trong thư mục hiện tại.
- `git branch -M main`: đổi tên nhánh hiện tại thành `main`.
- `git remote add origin <URL>`: khai báo Remote Repository có tên `origin`.
- `git add README.md`: đưa README.md vào vùng staging.
- `git commit -m "Add README.md file"`: tạo commit lưu lại thay đổi với thông điệp mô tả.
- `git push -u origin main`: đẩy nhánh `main` lên remote `origin` và thiết lập nhánh theo dõi cho những lần push/pull sau.

## Cách chạy
Đây là repository thực hành Git/GitHub; không cần chạy ứng dụng. Hãy đọc README và xem lịch sử commit trên GitHub.
